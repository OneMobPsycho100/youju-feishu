# 报销预算管理

侧栏“预算管理”进入 `#/budgets`，支持按公司主体、审批表单申请部门和单一费用类别管理共享预算。类别留空表示部门全部费用。管理员和财务可维护、确认归属和释放预算冻结，所有已登录角色均可查询、查看原审批及导出。

## 创建与维护

填写名称、主体、部门、类别、周期、额度及备注。月度、季度和年度使用完整自然周期，自定义周期包含所选起止日期全天。日期按北京时间解释。部门及类别可从已有选项选择，也可输入新名称；部门按表单名称去除首尾空白后精确匹配。

范围和起止日期创建后固定；同一主体、部门、类别、起止日期禁止重复创建。复制时默认选择下一周期，可自行更改，不复制使用金额及调整记录。新建预算会自动统计周期内已建账的历史报销，历史建账进度在页面提示。

额度必须大于零，最多两位小数。调整额度填写调整后的总额和原因，保留调整前后额度、操作人、时间及独立版本。名称、备注、预警阈值可以维护。默认阈值80%，范围1%至100%。归档收纳历史预算并退出审批预算提醒，历史用量仍随权威审批更新；可恢复原预算。

默认列表展示覆盖北京时间今天的未归档预算，可切换历史、未来、归档预算，并筛选主体、部门、类别、周期、名称和预警状态。相交日期范围筛选会切换到全部周期。

## 金额口径

`可用余额 = 当前预算额度 - 已使用 - 在途占用 - 冻结占用`

| 状态 | 预算处理 |
| --- | --- |
| 飞书最终 APPROVED | 已使用 |
| PENDING | 在途预占，与是否完成预审无关 |
| 最终通过前拒绝、撤回、删除等终止 | 释放在途 |
| 曾最终通过后撤销等异常终止 | 冻结最后有效通过快照中的金额、归属和提交时间 |
| 财务核对后释放冻结 | 整单释放所有匹配预算中的冻结，保留核查依据 |

归入周期的时间为飞书申请提交时间，跨期通过仍归入原提交周期，不使用预审时间、最终通过时间或工作台采集时间。每张审批计一次整单申请金额，不按发票数量累加或跨主体分摊。已用金额不代表付款或入账。

月、季、年以及部门总预算、类别专项预算可以覆盖相同单据，分别核算；不同预算额度和用量不可相加作为企业总额。列表只汇总预算条目数、预警数和超额数。

使用率以已用、在途和冻结的总占用除以额度计算，达到阈值预警，达到100%显示额度用尽，超过100%显示实际使用率及超出金额，可用余额保留负数。预算只提醒，不改变人工或自动预审资格和审核结论。审批详情中的余额已经包含本单当前占用，不需要再次扣减本单。

## 归属和冻结核对

预算部门只取表单中的部门映射；没有显式映射时仅接受唯一明确命名的“申请部门／所属部门／部门”字段，不回退报销人组织部门。多选、缺少名称或存在歧义均待确认。

主体优先根据表单实际申报名称、允许别名和税号唯一匹配。没有申报主体时才允许使用唯一票据主体；多主体或不完整申报不会自动把整单金额扣到多个公司。

“待归属／待补齐”展示无法确认主体、部门或提交时间的占用单据。管理员或财务填写依据，将整单归入一个主体和部门；这不修改飞书表单、票面或票据占用。来源后来发生变化，人工归属需要重新核对。缺少提交时间继续使用原有飞书元数据补齐任务，不伪造日期。

待归属、缺少时间的记录暂不扣减明确预算，完整性提示包含主体未知记录的数量和金额，余额可能偏高。已明确归属但没有匹配的未归档预算时，审批详情显示“未配置预算”。

“冻结待核对”支持核查后整单释放，操作绑定当时的用量版本和冻结快照。重复同步不会恢复已经释放的相同冻结；重新通过会重新计入已用，金额或归属等依据变化会产生新的核对依据。历史缺少通过快照时固定首次建账时的当前快照，并标记金额待核对。预算释放与管理员操作的发票冻结占用释放独立。

## 明细、分析和导出

预算详情显示金额指标，可点击已用、在途、冻结下钻明细，或按人员稳定身份和类别查看贡献；同名人员独立统计。趋势展示当前占用按提交时间的分布，90天以内按日，否则按月，空日期补零，不作为历史余额曲线。

Excel包含预算说明、金额汇总、全部报销明细和操作记录。明细超过50,000单明确报错，不截断导出；金额、编号和用户输入显式保存为文本。归属调整前后关联预算均保留可追溯的操作记录。

业务助手通过 `query` 的 `budgets`、`budget`、`budget_usages` 只读对象查询余额、贡献及明细。沿用公司筛选、角色权限和预算共用服务，额度调整、归属确认及冻结释放在网页处理。

## 数据与接口

迁移 `0019_reimbursement_budgets` 新增预算、每单用量、操作记录三张表。采集、审核主体更新和统计元数据补齐在原短写事务中更新用量，审批ID唯一，重复事件不累计扣减。金额沿用整数分存储和Decimal计算，HTTP以元的十进制字符串传输。

历史建账使用 `BUDGET_USAGE_BACKFILL` 任务，每轮安排20单，独立于飞书接入及自动同步开关；只使用本地已保存表单。新周期不自动结转余额。正式环境不初始化预算；演示环境补充正常、预警、超额、冻结及待归属样例，重复启动保留已修改额度和核查记录。

接口均位于 `/api/v1`，`/api/docs`提供中文字段说明。写操作除创建外携带 `expected_version`；额度调整、归属和冻结释放同时携带 `request_id` 与 `reason`，网络重试复用请求标识，相同标识更换参数返回409。

| 方法与地址 | 作用 |
| --- | --- |
| GET /budgets | 筛选、分页、使用进度及完整性提示 |
| GET /budgets/options | 部门和类别选项 |
| POST /budgets | 创建预算 |
| GET /budgets/{id} | 预算详情、人员类别贡献及分布 |
| PATCH /budgets/{id} | 名称、备注、阈值及归档维护 |
| POST /budgets/{id}/adjustments | 调整后的总额度与核查依据 |
| GET /budgets/{id}/details | 按状态、人员或类别下钻分页明细 |
| GET /budgets/{id}/history | 预算维护及关联报销操作记录 |
| GET /budgets/{id}/export | 完整单项预算Excel |
| GET /budgets/usages | 待归属、冻结等用量查询 |
| POST /approvals/{id}/budget-attribution | 整单预算主体与部门确认 |
| POST /approvals/{id}/budget-release | 整单释放冻结预算 |

审批详情增加可空的 `budget_context`，包含本单用量、匹配预算和提示；付款申请为空。预算维护版本、预算用量版本和审批审核版本相互独立。未登录返回401，越权写入返回403，版本或幂等冲突返回中文409。

按项目要求不新增测试用例。开发验证使用类型检查、生产构建、Python编译、隔离库迁移与人工核算检查。
